1. Versões e suporte (out/2026)

PHP tem release major anual. O estável atual é o ramo 8.5 (ex.: 8.5.11, set/2026), suporte ativo até 31/12/2027. O 8.4 (ex.: 8.4.26) tem suporte ativo até 31/12/2026. O 8.3 (sua máquina: 8.3.35) recebe só segurança — serve para estudar, migre em projeto novo. O 8.6 estava em RC: não usar em produção.

Ramo PHPStatus
8.5Pipe |>, closures em constantes, cast em constantes, extensão URI, cURL ampliado.
8.4Property hooks, asymmetric visibility, nova API DOM HTML5, atributo #​[Deprecated].
8.3Base mínima do Laravel 13. Estude aqui, entregue em 8.4/8.5.

Laravel: major anual (~Q1), 18 meses de bug fixes + 2 anos de segurança. 13.x (mar/2026, ex. framework 13.35.0) exige PHP 8.3+. 12.x só segurança até 24/fev/2027 (use 12.69.0+). 11.x em fim de vida (mar/2026). Regra: projeto novo = Laravel 13 + PHP 8.5 (ou 8.4). Rode composer audit --locked no CI.

3. Sintaxe, tipos e variáveis

Todo arquivo começa com <?php. Variáveis sempre com $. Use declare(strict_types=1);.

Python / JSPHP
nome = 'Ana'$nome = 'Ana';
def soma(a:int,b:int)->intfunction soma(int $a, int $b): int
f-string / template literal"Olá $nome" interpola; 'Olá '.$nome concatena
cond ? x : yigual + $y = $a ?? $b;

Tipos: string, int, float, bool, null, array, object, callable, iterable, mixed, void, never. União int|string, nulável ?string.

declare(strict_types=1);
function adulto(?int $idade): bool {
  return ($idade ?? 0) >= 18;
}

6. OOP moderna no PHP 8

-> acessa membro (como .), :: acessa estático, $this é o self do Python.

class User {
  public function __construct(
    public string $nome,
    private int $idade = 18,
  ) {}
  public static function anonimo(): self {
    return new self('Anonimo');
  }
}
RecursoUso
Constructor promotionDeclara + atribui no construtor (acima). Menos boilerplate.
readonlyEscrita única. Ideal p/ DTOs.
Enumsenum Status: string { case Ativo='ativo'; }
TraitsMixins. Ex.: use SoftDeletes;
Attributes#[...] — metadados via Reflection; Laravel 13 usa em rotas e validação.

14. API REST: Resources e paginação

Nunca retorne o Model cru em API pública — use API Resource (no 13 há também JSON:API resources).

class TaskResource extends JsonResource {
  public function toArray($req): array {
    return ['id' => $this->id,
            'titulo' => $this->titulo,
            'done' => $this->done];
  }
}
return TaskResource::collection(
  Task::with('user')->paginate(15));

201 POST · 204 DELETE · 422 validação · 401 sem login · 403 sem permissão · 404 inexistente.
